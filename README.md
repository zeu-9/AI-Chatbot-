# 🧠 AI Washing Machine Recommender

An intelligent recommendation system that suggests the most suitable washing machines based on user preferences using Machine Learning and Generative AI.

This project combines data-driven filtering with a conversational AI interface to provide personalized product recommendations along with human-like explanations.

---

## 🚀 Features

* 🔍 Smart recommendation system based on user input
* 🤖 AI-generated explanations using API
* 📊 Data filtering and ranking of products
* 💬 Interactive UI built with Streamlit
* ⚡ Real-time responses with fallback handling

---

## 🛠️ Tech Stack

* Python
* Pandas & NumPy
* Streamlit
* Groq & Ollama API (Generative AI)

---

## 🎯 How It Works

1. User enters preferences (budget, type, capacity, etc.)
2. System filters relevant washing machines from dataset
3. AI model generates a natural-language explanation
4. Results are displayed in an interactive UI

---

## 📌 Note

This project uses the Groq API.
You must provide your own API key to run the application (see setup instructions).

---

## 💡 Use Case

Helps users quickly choose the best washing machine without manually comparing multiple products, making the decision process faster and easier.
